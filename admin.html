상품등록

카테고리 관리

여기서 카테고리를 직접 추가·수정·삭제할 수 있어요. 기존 카테고리 안에 하위 카테고리도 계속 만들 수 있습니다.

숨긴 카테고리와 그 하위 카테고리·상품은 고객페이지에서 모두 보이지 않아요. 관리자페이지의 상품과 주문 데이터는 삭제되지 않고 그대로 유지됩니다.

상품 등록

엑셀 등록 대기 상품 수정 중 ·
저장하면 엑셀등록 탭의 대기 목록에 반영돼요. 아직 쇼핑몰에 등록된 상태는 아니에요.
여러 장을 한 번에 선택할 수 있어요. 사진을 선택하면 바로 미리보기가 보여요 🤍
브랜드를 입력한 뒤 ‘브랜드 고정하기’를 누르면 상품 등록 후에도 브랜드가 유지돼요.
비워두면 상품명을 보고 자동으로 분류해요. 틀리면 직접 골라주세요.
사이즈표 상품은 가격·색상·사이즈 옵션 없이 등록할 수 있어요.
사이즈를 입력한 뒤 ‘사이즈 고정하기’를 누르면 상품 등록 후에도 사이즈가 유지돼요.
체크하면 고객 페이지에 “컬러 1 / 컬러 2” 선택칸이 따로 나와요. 위 컬러 목록에서 2개를 고르는 방식이고, 같은 컬러를 2개 골라도 돼요. 엑셀로 올릴 때는 “1+1” 열에 O 또는 1+1 이라고 적으면 돼요. (열이 없으면 상품명에 1+1이 들어간 상품은 자동 체크돼요)
상품가를 입력하면 회원가가 자동으로 채워져요 (기본 25% 할인, ACC 카테고리는 20% 할인, 도매가와는 최소 1,000원 차이). 도매가는 관리자 전용 별도 저장소에 보관돼 고객용 상품 데이터에 포함되지 않아요.
카테고리를 선택한 뒤 ‘카테고리 고정하기’를 누르면 상품 등록 후에도 선택이 유지돼요.
여러 카테고리를 선택하면 같은 상품이 선택한 카테고리에 각각 등록돼요.

엑셀등록

엑셀 · 이미지 ZIP 올리기

엑셀 1개와 상품명 폴더별 이미지가 들어 있는 ZIP 파일을 올리면 아래 등록 대기 목록이 만들어져요. 미리보기와 수정을 마친 뒤 상품 반영하기를 눌러야 쇼핑몰에 등록돼요.
엑셀 열: 브랜드명 · 상품명 · 색상 · 사이즈 · 도매가 · 소매가 (회원가 열이 있으면 사용, 없으면 상품가의 25% 할인 · ACC는 20% 할인) / 이미지 폴더 이름은 엑셀의 상품명과 같아야 해요.
ZIP을 여러 개 한꺼번에 선택해도 돼요. 엑셀은 어느 ZIP에 들어 있어도 되고, 엑셀이 없는 ZIP의 이미지도 상품명 폴더 이름으로 자동으로 이어 붙여요.

등록 대기 상품

카드를 누르면 미리보기, 수정을 누르면 상품등록 탭의 입력 화면에서 수기로 등록할 때처럼 수정할 수 있어요. 아직 쇼핑몰에는 등록되지 않은 상태예요.

회원 관리

가입한 회원은 승인 전까지 회원가가 적용되지 않아요.

휴대폰 승인요청 · 주문 알림
알림을 켜면 새 회원 승인요청과 새 주문이 들어올 때 휴대폰으로 알려드려요. 관리자 계정마다 기기에서 한 번씩 설정해주세요.
오픈채팅방 닉네임 ↔ 회원 대조

오픈채팅방 참여자 닉네임을 한 줄에 하나씩 붙여넣고 대조하기를 누르세요. 닉네임에 이름이나 전화번호(뒤 4자리 포함)가 들어 있으면 가입한 회원과 자동으로 맞춰봐요. 이름·연락처가 적힌 텍스트/CSV/엑셀 파일, 카카오톡 대화 내보내기(.txt) 파일도 올릴 수 있어요.
