엑셀 상품 가져오기

업체에서 받은 알집 ZIP 파일을 그대로 올려도 됩니다. ZIP 안의 엑셀 단가표와 상품별 사진 폴더를 자동으로 찾아 연결합니다. 엑셀과 사진 ZIP을 따로 선택하는 방식도 지원합니다.

업체마다 다른 열 이름과 파일명 규칙을 자동으로 분석합니다. 사진 연결이 불확실하거나 가격 구조가 여러 개인 상품은 등록 전 미리보기에서 반드시 확인해주세요. 실제 등록은 아래 등록 버튼을 누른 뒤에만 진행됩니다.

ZIP은 한 업체씩 올려주세요. 알집 .alz 형식은 브라우저에서 직접 해제할 수 없으므로 .zip으로 압축해 올려주세요.

상위·하위 카테고리를 한눈에 확인할 수 있어요. 선택한 카테고리에 상품이 등록됩니다.

각 상품의 ‘고객 화면 미리보기’에서 실제 고객 화면 형태로 확인한 뒤, 아래 ‘반영하기’를 눌러야 사이트에 등록됩니다.

카테고리 관리

여기서 카테고리를 직접 추가·수정·삭제할 수 있어요. 기존 카테고리 안에 하위 카테고리도 계속 만들 수 있습니다.

숨긴 카테고리와 그 하위 카테고리·상품은 고객페이지에서 모두 보이지 않아요. 관리자페이지의 상품과 주문 데이터는 삭제되지 않고 그대로 유지됩니다.

상품 등록

여러 장을 한 번에 선택할 수 있어요. 사진을 선택하면 바로 미리보기가 보여요 🤍
브랜드를 입력한 뒤 ‘브랜드 고정하기’를 누르면 상품 등록 후에도 브랜드가 유지돼요.
사이즈표 상품은 가격·색상·사이즈 옵션 없이 등록할 수 있어요.
사이즈를 입력한 뒤 ‘사이즈 고정하기’를 누르면 상품 등록 후에도 사이즈가 유지돼요.
상품가를 입력하면 회원가가 자동으로 25% 할인된 금액으로 채워져요. 도매가는 관리자 전용 별도 저장소에 보관돼 고객용 상품 데이터에 포함되지 않아요.
카테고리를 선택한 뒤 ‘카테고리 고정하기’를 누르면 상품 등록 후에도 선택이 유지돼요.
여러 카테고리를 선택하면 같은 상품이 선택한 카테고리에 각각 등록돼요.
